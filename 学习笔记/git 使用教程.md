## git 使用教程

### 1.环境

```
ubuntu 26.02
```

### 2.安装

```bash
sudo apt install git
```

### 3.配置

```bash
git config --global user.name "github用户名"
git config --global user.email "邮箱账号"
```

### 4.使用教程

- #### 克隆仓库

```bash
git clone https://github.com/用户名/仓库名.git
```

- #### 查看状态

```bash
git status
```

- #### 更新仓库

```bash
git pull
```

- #### 加入暂存区

```
git add .
```

- #### 提交

```
git commit -m "备注"
```

- #### 上传

```
git push
```
