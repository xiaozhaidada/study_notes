## RK3588

### 1.  .ONNX---> .RKNN

- #### 推荐环境

```cmd
ubuntu 22.04 x86_64
Python 3.10
RKNN—Toolkit2 2.3.x
```

- #### 安装

```cmd
# 创建 python3.10 的环境
conda create -n rknn python=3.10 -y
# 下载 RKNN—Toolkit2
git clone https://github.com/airockchip/rknn-toolkit2.git
cd ~/rknn/rknn-toolkit2
rknn_toolkit2-2.3.2-cp310-cp310-manylinux_2_17_x86_64.manylinux2014_x86_64.whl
```

- #### 模型转换

```python
from rknn.api import RKNN

ONNX_MODEL = './model.onnx'
RKNN_MODEL = './model.rknn'

rknn = RKNN(verbose=True)

# 1. 配置目标平台
print('--> Config model')
ret = rknn.config(
    target_platform='rk3588'
)
if ret != 0:
    print('Config model failed!')
    exit(ret)

# 2. 加载 ONNX
print('--> Loading ONNX model')
ret = rknn.load_onnx(
    model=ONNX_MODEL
)
if ret != 0:
    print('Load ONNX failed!')
    exit(ret)

# 3. 构建 RKNN
print('--> Building RKNN model')
ret = rknn.build(
    do_quantization=False
)
if ret != 0:
    print('Build RKNN failed!')
    exit(ret)

# 4. 导出
print('--> Export RKNN model')
ret = rknn.export_rknn(
    RKNN_MODEL
)
if ret != 0:
    print('Export RKNN failed!')
    exit(ret)

rknn.release()

print('Done:', RKNN_MODEL)
```

### 2. .RKNN的运行

- #### 推荐环境

```cmd
RK3588
Linux aarch64
RKNN-Toolkit-Lite2（python）
librknnrt.so   rknn_api.h（c/c++）
```

- #### python

```python
from rknnlite.api import RKNNLite

rknn = RKNNLite()

ret = rknn.load_rknn("resnet50_rk3588.rknn")
assert ret == 0

ret = rknn.init_runtime(
    core_mask=RKNNLite.NPU_CORE_AUTO
)
assert ret == 0

outputs = rknn.inference(
    inputs=[input_data]
)

rknn.release()
```

- #### c/c++

```c++
rknn_context ctx;

rknn_init(
    &ctx,
    model_data,
    model_size,
    0,
    nullptr
);

rknn_query(...);

rknn_inputs_set(...);

rknn_run(ctx, nullptr);

rknn_outputs_get(...);

rknn_outputs_release(...);

rknn_destroy(ctx);
```

```cmd

```

|      参数       |        含义        |
| :-------------: | :----------------: |
|   onnx_model    |   ONNX 模型位置    |
| TARGET_PLATFORM | 运行平台（rk3588） |
|      dtype      | 量化类型（fp，i8） |
|     output      |   RKNN 文件位置    |
