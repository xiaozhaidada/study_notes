## RK3588 的 int8 量化

### 1. 阶段

```
onnx 文件 -----> 量化 -----> rknn 文件
```

### 2. PTR（训练后量化）

```cmd
# 文件结构
dataset/
  001.jpg
  002.jpg
  ...
	
dataset.txt/
  ./dataset/001.jpg
  ./dataset/002.jpg
  ...
```

```python
###### rknn 配置
# 默认
ret = rknn.config(
    target_platform='rk3588'
)

# PTR
rknn.config(
    mean_values=[[x, y, z]],
    std_values=[[x, y, z]],
    target_platform='rk3588'
)
######

##### rknn构建
# 默认
ret = rknn.build(
    do_quantization=False
)

# PTR
ret = rknn.build(
    do_quantization=True,
    dataset='./dataset.txt'  // 量化参数集
)
#####
```
