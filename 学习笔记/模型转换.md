## 模型转换

### .pt ----> .onnx

#### 1.PyTorch 官方导出

```python
import torch

# 加载 .pt 模型
model = torch.load("model.pt")

# 导出 ONNX
torch.onnx.export(model,dummy_input,"model.onnx")
```

#### 2.Ultralytics(yolo系列)

```cmd
# 安装
pip install ultralytics

# 导出
yolo export model=model.pt format=onnx
```



### .onnx ----> .engine (nvidia TensorRT)

#### 1.TensorRT  trtexec

##### 前提：NVIDIA GPU； CUDA； cuDNN;  TensorRT

```cmd
trtexec 
  --onnx=model.onnx 
  --saveEngine=model.engine
```



### .onnx ----> .rknn (瑞芯微)

#### 1.RKNN Toolkit2（PC端转换）   RKNN Runtime（板端运行）

```cmd
# 安装
pip install rknn_toolkit2
```

```python
from rknn.api import RKNN


ONNX_MODEL = './yolov8n.onnx'
RKNN_MODEL = './yolov8n.rknn'


# RK3588
TARGET_PLATFORM = 'rk3588'


rknn = RKNN()


# 1. 配置模型
print('--> Config model')

rknn.config(
    target_platform=TARGET_PLATFORM,
    mean_values=[[0,0,0]],
    std_values=[[255,255,255]]
)


# 2. 加载ONNX
print('--> Load ONNX')

ret = rknn.load_onnx(
    model=ONNX_MODEL
)

if ret != 0:
    print("load onnx failed")
    exit(ret)


print("ONNX loaded")


# 3. 编译RKNN

print('--> Build RKNN')


ret = rknn.build(
    do_quantization=False
)


if ret != 0:
    print("build failed")
    exit(ret)


print("Build done")


# 4. 导出

print('--> Export RKNN')

ret = rknn.export_rknn(
    RKNN_MODEL
)


if ret != 0:
    print("export failed")
    exit(ret)


print("RKNN saved")


rknn.release()
```
