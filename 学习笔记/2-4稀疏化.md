## 2:4 稀疏化

### 1. 阶段

```
PyTorch 模型 -----> Model Optimizer 2:4 稀疏化 -----> ONNX 模型
```

### 2. 安装环境

```cmd
ubuntu 22.04

pip install nvidia-modelopt
```

### 3. 2:4 稀疏化

```python
import torch
from torchvision.models import resnet50
import modelopt.torch.sparsity as mts


# ==============================
# 1. 参数
# ==============================

PT_PATH = "resnet50.pth"
ONNX_PATH = "resnet50_sparse.onnx"


# ==============================
# 2. 创建 ResNet50
# ==============================

model = resnet50(weights=None)


# ==============================
# 3. 加载 .pth 权重
# ==============================

state_dict = torch.load(
    PT_PATH,
    map_location="cpu"
)

model.load_state_dict(state_dict)

model = model.to(device)
model.eval()

print("Dense model loaded.")


# ==============================
# 4. Model Optimizer 2:4 稀疏化
# ==============================

sparse_model = mts.sparsify(
    model,
    mode="sparse_magnitude",
)

sparse_model.eval()

print("2:4 sparsification finished.")


# ==============================
# 5. 导出普通 PyTorch sparse model
# ==============================

sparse_model = mts.export(sparse_model)

sparse_model.eval()

print("Sparse mask applied to weights.")


# ==============================
# 6. 构造 ONNX 输入
# ==============================

dummy_input = torch.randn(
    1,
    3,
    224,
    224,
)


# ==============================
# 7. 导出 ONNX
# ==============================

torch.onnx.export(
    sparse_model,
    dummy_input,
    ONNX_PATH,

    input_names=["input"],
    output_names=["output"],

    opset_version=13,
)

print(f"ONNX exported to: {ONNX_PATH}")
```

### 4. 在 orin 上运行

```cmd
trtexec \
  --onnx=resnet50_sparse.onnx \
  --saveEngine=resnet50_sparse.engine \
  --fp16 \
  --sparsity=enable \  // 支持稀疏化
  --verbose
```
